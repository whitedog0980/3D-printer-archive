### 브레인스토밍(메모장)
* 단순한 형상을 만들기 보다, 기능이 있으면 좋겠다.
* 전시 기능을 만들고 싶다
* **내부 디자인 안1** : gpu의 모양에 맞게 수작구멍을 만든다.
    * 장점 : 보기 좋다, 제작 용이하다
* **내부 디자인 안2** : 기본적으로 일반적인 상자모양에 GPU 거치대를 별도제작하여 넣는다.
    * 장점 : 필라멘트 소모량이 적다, 추후 GPU 상자 외의 용도로 사용 가능하다.
* **아이디어** : 차라리 그리니티 상자를 출력하고, 내부 거치대를 만드는것이 더 간단하게 구현할 수 있지 않은가?
* **아이디어** : 상자의 본체, 뚜껑을 분리하여 조인트로 연결, 필요시 뚜껑을 뒤집어 사선으로 고정 및 전시
* **아이디어** : 6면체형으로 만들되, 사이즈를 최소화 하고싶다. 동시에 GPU전용이 아닌 다용도 케이스로 만들고 싶다. (디자인안2와 연계)
* **아이디어** : 겸사겸사 방습 * 방진도 하고 싶다. TPU로 PCIE 단자 보호대도 만들고 싶다.
* **아이디어** : GPU의 단자 패널 부분이 돌출되어 있다. 이부분을 이용하면 쉽게 고정되는 디자인을 만들 수 있을듯 하다.
* **구체화** : 상자의 두께를 정해야한다. -> 다른 케이스 레퍼런스 참조 -> 단순 벽6개
