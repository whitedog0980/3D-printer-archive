# 스위치 케이스 제작
> 스위치 케이스가 노후되어 결합부분이 부러져 새로 제작
* 
## 사용 하드웨어
| 종류 | 명칭 |
| :---: | :--- |
| 3d 프린터 | Bambulab A1 |
| 필라멘트 | ... |
| 공구 | 줄자 |

## 사용 소프트웨어
| 종류 | 명칭 |
| :---: | :--- |
| 슬라이서 | Bambu Studio |
| 모델링 툴 | Autodesk Fusion |

### 참고 사진
![부서진 스위치 커버](/asset/brockenSwitchCase.png )
* 왼쪽 결합부가 부러짐

### 브레인스토밍(메모장)
* 결합부 부분을 출력한다면 적층결이 수평이므로 내구도가 약할것이다
* 차라리 돌출된 부분에 빡빡한 공차를 춘 벽을 만들어 결합시키는것이 내구적으로 좋을것이다.
* 버니어 캘리퍼스가 있다면 좋겠지만, 줄자밖에 없기에 한번에 만들기보다 테스트 모델을 제작하는것이 좋을것 같다.
* 하지만 애초에 소모하는 필라멘트가 적기에 딱히 상관없을것 같다.
* 스위와 벽면에 곡면이 있다. 이부분은 케이스가 더 작은 곡면을 가지기만 하면 간섭은 없을것이다.

![스위치 커버 스케치](/asset/switchCoverSlicer.png )
3. 출력 후 장착
