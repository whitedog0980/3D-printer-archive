# 스카디스 120mm 팬 마운트 제작
> 책상 아래 스카디스 패널 가장자리에 120mm PWM 팬을 달아 PC 주변에 바람을 보내기 위한 거치대.
> 팬 각도를 바꿀 수 있어야 하고, USB-C 팬 컨트롤러(컨트롤 블록)도 같이 붙어 있어야 한다.

## 사용 하드웨어
| 종류 | 명칭 |
| :---: | :--- |
| 3d 프린터 | Bambulab A1 |
| 필라멘트 | PETG 권장 (PLA도 가능) |
| 팬 | 120mm 4pin PWM 팬 (ARCTIC, 두께 25mm, 나사구멍 간격 105mm) |
| 컨트롤 블록 | USB-C 입력 / 4pin 출력 팬 속도조절 모듈 (44.90 × 21.92 × 17.40mm) |
| 공구 | 디지털 버니어 캘리퍼스 |
| 체결 | **M3×40 나사 4개** (너트 없음) / 틸트 애드온 사용 시 **+3개 = 총 7개** |

## 사용 소프트웨어
| 종류 | 명칭 |
| :---: | :--- |
| 슬라이서 | Bambu Studio |
| 모델링 툴 | Python + manifold3d (파라메트릭 스크립트, Claude로 작성) |

## v1 (폐기) — 고프로식 2축 암
* 스카디스 훅 베이스 → 3발/2발 고프로식 힌지 → 50/80mm 암 → 팬 브래킷, M5 볼트+너트 2세트.
* 피드백
  1. **M5 볼트/너트가 따로 필요** — 갖고 있는 철물은 M3×40뿐.
  2. 80mm 암 끝에 팬이 매달리는 캔틸레버 구조라 **팬 무게를 마찰 힌지가 버티기 어려움**.
  3. 팬이 패널에서 너무 멀다 — **힌지는 패널 1cm 이내**, 팬은 최대한 가까이.
  4. 컨트롤 블록 홀더를 패널에 따로 거는 방식이었음 → **팬/마운트에 일체화**하고 **케이블 정리**까지 필요.

## v2 — 패널 가장자리에 문처럼 다는 2힌지 구조
### 브레인스토밍(메모장)
* 스케치대로 **한 축 위에 힌지 2개** (문 경첩 방식). 팬 위·아래 끝에 하나씩 → 두 힌지 중심 간격 76mm(바깥 끝 기준 120mm)로 하중 분산, 캔틸레버 없음.
* 힌지 핀 = **M3×40 나사** 그 자체. 머리는 바깥 패널 너클 카운터보어, 나사산은 안쪽 패널 너클(2.75mm 구멍)에 직접 셀프탭.
  * 패널쪽 너클(P) – 팬쪽 너클(F) – 패널쪽 너클(P) 순서. 나사를 조이면 P 두 개가 F를 양쪽에서 눌러 **마찰로 각도 유지**.
  * 나사가 패널쪽 부품에만 물려 있어서 팬을 돌려도 나사가 같이 돌지 않음 → 풀림 없음.
* 팬 고정도 **M3×40** — 팬 두께 25 + 뒤 플랜지 4 + 앞 플랜지/보스 11 = 정확히 40mm. 나사 끝이 보스 끝과 일치.
* 힌지 축 위치: 패널 앞면에서 **6.5mm**, 패널 끝에서 2mm 바깥. 팬 옆면은 축에서 10mm.
* 컨트롤 블록: 스케치처럼 **팬 바로 아래, 힌지 쪽**에 슬리브로 일체화. 노브 면이 앞(팬 정면과 같은 방향), USB-C/4pin 면이 뒤.
  * 앞뒤 모두 큰 창, 블록은 바깥쪽 열린 끝으로 밀어 넣고 끝단 걸림턱(0.6mm)으로 고정.
* 케이블: 블록 뒤 창 → 브래킷의 클립(슬리브 옆) → 브래킷 클립(가운데) → **두 힌지 사이 32mm 빈 공간**으로 축을 넘어감 → 패널쪽 클립 → 패널로.
  * 축 근처로 넘기면 팬을 돌려도 케이블 길이 변화가 거의 없다.
* 패널 고정은 v1에서 검증한 **훅 + 잠금 키** 재사용(철물 불필요). 훅 2개를 가장자리 열의 80mm 떨어진 슬롯 2개에 건다.

### 출력 방향 / 시행착오
1. 팬 브래킷을 뒷면을 베드에 놓고 출력하면 **앞 플랜지가 14mm 허공 캔틸레버** → 실패.
   * 해결: **세워서 출력**(슬리브 바닥이 베드). 웹·플랜지·힌지 너클이 전부 수직 벽이 되고 너클 구멍도 수직.
   * 앞쪽 나사 보스와 케이블 클립 아래에 45° 거셋을 넣어 서포트 없이 출력.
2. 세워서 출력하면 **팬쪽 너클(F) 아랫면 2곳**은 마찰면이라 깎을 수 없어서 오버행으로 남음 → 여기만 서포트 사용.
3. F 너클을 뒤판까지 보강하는 웹이 처음엔 **패널 모서리를 파고듦**(간섭 58mm³) → 45° 평면으로 잘라 패널 모서리를 피하면서 그 면 자체가 출력 가능한 경사가 되도록 함.
4. 블록 걸림턱이 블록 끝과 겹침 → 슬리브를 2.5mm 늘려서 블록과 턱 사이 0.4mm 여유 확보.
5. 회전 범위 확인: **0°(패널과 같은 평면) ~ 97°(패널 앞으로 직각 이상)** 간섭 없음. 0°에서 패널에 닿아 자연스러운 스토퍼가 됨.

## 조립
1. **패널 리프**의 훅 2개를 패널 가장자리 열의 슬롯 2개(80mm 간격)에 꽂고, 아래로 약 7mm 밀어 건다 → **잠금 키**를 위쪽 홈에 꽂는다.
2. 컨트롤 블록을 **노브가 앞(브래킷 앞 플랜지 방향), USB-C가 뒤**로 오게 슬리브 열린 끝으로 밀어 넣는다.
3. 팬을 브래킷 C채널에 끼우고, **M3×40 2개**를 뒤쪽에서 팬 모서리 구멍을 통해 앞 보스에 조인다.
4. 팬쪽 너클을 패널쪽 너클 사이에 맞추고 **M3×40 2개**를 위·아래 바깥쪽에서 꽂아 조인다. 원하는 뻑뻑함이 될 때까지 조임.
5. 케이블: USB-C → 뒤 창 → 브래킷 클립 2개 → 두 힌지 사이로 축을 넘어 → 패널 리프 클립. 4pin은 뒤 창에서 팬 커넥터로.

## v2 틸트 애드온 — 위아래 각도조절
> v2를 출력·장착한 뒤 추가 요청: 지금 힌지(좌우 스윙)에 더해 **팬을 위아래로 기울이는 축**을 붙이고 싶다.
> 이미 출력한 `panel_leaf` / `fan_bracket` / `lock_key`는 **그대로 쓰고** 부품만 추가한다.

### rev.1 (폐기) — 분할 필로우블록 클램프
* 팬 자리에 스파인을 끼우고, 팬 중심 높이의 X축 핀을 위아래 반쪽 블록으로 감싸 M3×40 2개로 조이는 방식.
* 축이 팬 무게중심을 지나서 균형은 맞았지만, **실제로 출력해 보니 너무 쉽게 움직여서 불편**했다.
  * 원통 클램프는 조여도 마찰면 압력이 고르지 않고, 블록이 조금만 휘어도 바로 헐거워진다.
* 피드백: **v2 좌우 힌지처럼 "나사를 조이는 만큼 빡빡해지는" 너클 힌지**를 원함.

### rev.2 (변경) — 나사 조임식 너클 힌지, 팬 위쪽
* v2 스윙 힌지와 같은 원리: **P(고정) – F(움직임) – P(고정)** 너클 3개를 M3×40 하나가 관통.
  나사가 축 핀이면서 동시에 너클을 눌러 주는 장력 조절 나사 → **조일수록 빡빡**.
  * 나사 머리는 P_head, 나사산은 P_tap에 박혀서 둘 다 고정쪽 → 팬을 움직여도 나사가 같이 돌지 않아 풀리지 않음.
* 틸트 축(X)에 나사를 꽂으면 드라이버도 X 방향으로 들어가야 한다. 축이 팬 중심을 지나면 한쪽은 팬, 반대쪽은 브래킷 웹에 막혀서 손이 안 닿음 → 축을 **팬 모서리 바깥**으로 옮기고, 육각렌치는 -X 끝에서 축을 따라 들어가게 함.
* rev.2는 축을 **팬 위쪽**에 두고 팬을 매다는 구조였음.
* 피드백: **힌지가 위쪽이 아니라 아래쪽**이 되도록.

### rev.3 — 나사 조임식 너클 힌지, 팬 아래쪽 (현재)
#### 브레인스토밍(메모장)
* 힌지 원리(P–F–P + M3×40 장력 나사, 휘는 기둥)는 rev.2 그대로, 구조 전체를 위아래로 뒤집어 **힌지가 팬 아래**에 오게 함. 팬은 힌지 위에 서 있는 형태.
* 문제: 팬 바로 아래에 이미 출력된 **컨트롤 블록 슬리브**(위면 y=-60)가 있다.
  * 힌지 아래 레일이 슬리브 위를 지나가야 하고, 기울일 때 팬 아래쪽 모서리와 크래들 패드가 축 아래로 쓸고 내려옴.
  * 축이 슬리브보다 낮으면 조금만 기울여도 팬이 슬리브에 닿음 → **팬을 올리는 수밖에 없음**.
* 팬 높이별 틸트 가능 범위(계산):

  | 팬 바닥 `FB_W` | v2 대비 | 레일 두께 | 틸트 범위 |
  | :---: | :---: | :---: | :---: |
  | -37 | +23mm | 5.2 | -55° ~ +75° |
  | **-33 (채택)** | **+27mm** | **9.2** | **-70° ~ +75°** |
  | -29 | +31mm | 13.2 | -80° ~ +80° |
  | -25 | +35mm | 17.2 | -80° ~ +90° |

  → 레일이 충분히 두껍고 범위도 넉넉한 **-33** 채택. 팬은 y -33 ~ 87 (브래킷 위로 27mm 올라옴).
* 고정쪽 프레임(`tilt_frame`) = 브래킷 채널에 끼우는 스파인 + 슬리브 바로 위를 지나는 레일 + P 너클 2개. (rev.2의 위쪽 기둥 없어짐 → 더 작아짐)
* 팬은 **아래쪽 모서리 구멍 2개**로 크래들(`tilt_cradle`)에 고정. 나사는 팬 앞면에서 넣어 크래들 뒤 패드에 조임.
* 팬이 스파인 바로 옆(1mm)에 붙음 → 팬 중심 거리 70(v2) → **85mm**.

#### 시행착오 / 검증
1. **나사를 조여도 안 빡빡해지는 문제(rev.2 설계 단계)**: P_head와 P_tap이 같은 레일에 단단히 붙어 있으면 둘 사이를 0.5mm 좁힐 수 없어서 조임력이 마찰로 안 간다.
   * 해결: P_head를 레일에 직접 붙이지 않고, 끝단의 **얇은 기둥(3.5mm, 자유길이 10mm)에만 매달아 휘게** 함. 기둥이 휘는 데 약 130N, 그 이상 조이는 힘이 전부 너클 마찰로 감.
2. 레일이 힌지 바로 옆을 지나가서 **+35°만 기울여도 크래들 너클 받침이 레일에 닿음**(rev.2).
   * 해결: 움직이는 너클(F) 구간만 레일을 **아치처럼 25mm 바깥으로** 뺌. rev.3에서는 아치가 아래로 향하는데, F 구간(x -94~-76)이 슬리브(x -60~-10) 바깥이라 슬리브와 안 겹침.
3. 프레임은 등을 베드에 대고 눕혀서 출력(레일이 베드에 붙음 → 굽힘 방향이 층 안쪽이라 튼튼). 이걸 맞추려고 힌지 축을 팬 중심면보다 6.3mm 뒤(`ZA`)에 둠.
4. rev.3는 코드를 "힌지가 위" 로컬 좌표로 그대로 쓰고 마지막에 **위아래 미러**만 해서 만듦 → rev.2의 검증된 형상(휘는 기둥, 아치, 받침 각도)을 그대로 유지. 출력 방향(뒷면이 베드)도 미러와 무관.
5. 크래들 케이블 클립을 슬리브 위(x≈-36)에 두면 기울일 때 슬리브를 침 → 팬 반대쪽 끝(x=-125)으로 옮김.
6. 검증 결과 (rev.3)
   * 틸트: **-70°(팬 윗면이 앞으로) ~ +75°(뒤로)** 간섭 없음 (5° 간격, 중간에 끊김 없음)
   * 좌우 스윙: 틸트 -70/-35/0/35/75°에서 모두 **0~95°** (v2와 동일)
   * 틸트 나사 육각렌치 경로: 모든 틸트 각도에서 막힘 없음 / v2 힌지 나사 접근도 그대로
   * 두 STL 모두 워터타이트, 각각 한 덩어리, 서포트 불필요(작은 나사구멍 천장만)

#### 조립 (v2에 추가)
1. 브래킷에서 **팬을 뺀다** (팬 나사 2개 풀기).
2. **프레임**의 스파인을 팬 자리(C채널)에 끼우고, 빼 둔 **M3×40 2개**로 원래처럼 조인다. 레일이 슬리브 바로 위로 지나감.
3. 크래들의 너클(F)을 프레임의 두 너클 사이에 넣고, **M3×40 1개**를 바깥쪽(-X) 끝 P_head 쪽에서 꽂아 P_tap까지 조인다.
4. 팬을 크래들 위에 세우고 **M3×40 2개**를 팬 앞면에서 아래쪽 모서리 구멍 → 크래들 뒤 패드로 조인다.
5. 팬을 원하는 각도로 맞추고, 힌지 나사를 조여 **빡빡함을 조절**한다. 조일수록 단단히 고정됨.
6. 케이블: 팬 케이블 → 크래들 끝 클립 → 프레임 레일 끝 클립 → 기존 브래킷 클립.
