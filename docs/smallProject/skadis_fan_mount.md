# 스카디스 120mm 팬 마운트 제작
> 책상 아래 스카디스 패널 가장자리에 120mm PWM 팬을 달아 PC 주변에 바람을 보내기 위한 거치대.
> 팬 각도를 바꿀 수 있어야 하고, USB-C 팬 컨트롤러(컨트롤 블록)도 같이 붙어 있어야 한다.

## 사용 하드웨어
| 종류 | 명칭 |
| :---: | :--- |
| 3d 프린터 | Bambulab A1 |
| 필라멘트 | PETG 권장 (PLA도 가능) |
| 팬 | 120mm 4pin PWM 팬 (ARCTIC, 두께 25mm, 나사구멍 간격 105mm) |
| 컨트롤 블록 | USB-C 입력 / 4pin 출력 팬 속도조절 모듈 (44.90 × 21.92 × 17.40mm) |
| 공구 | 디지털 버니어 캘리퍼스 |
| 체결 | **M3×40 나사 4개** (너트 없음) |

## 사용 소프트웨어
| 종류 | 명칭 |
| :---: | :--- |
| 슬라이서 | Bambu Studio |
| 모델링 툴 | Python + manifold3d (파라메트릭 스크립트, Claude로 작성) |

## v1 (폐기) — 고프로식 2축 암
* 스카디스 훅 베이스 → 3발/2발 고프로식 힌지 → 50/80mm 암 → 팬 브래킷, M5 볼트+너트 2세트.
* 피드백
  1. **M5 볼트/너트가 따로 필요** — 갖고 있는 철물은 M3×40뿐.
  2. 80mm 암 끝에 팬이 매달리는 캔틸레버 구조라 **팬 무게를 마찰 힌지가 버티기 어려움**.
  3. 팬이 패널에서 너무 멀다 — **힌지는 패널 1cm 이내**, 팬은 최대한 가까이.
  4. 컨트롤 블록 홀더를 패널에 따로 거는 방식이었음 → **팬/마운트에 일체화**하고 **케이블 정리**까지 필요.

## v2 — 패널 가장자리에 문처럼 다는 2힌지 구조
### 브레인스토밍(메모장)
* 스케치대로 **한 축 위에 힌지 2개** (문 경첩 방식). 팬 위·아래 끝에 하나씩 → 두 힌지 중심 간격 76mm(바깥 끝 기준 120mm)로 하중 분산, 캔틸레버 없음.
* 힌지 핀 = **M3×40 나사** 그 자체. 머리는 바깥 패널 너클 카운터보어, 나사산은 안쪽 패널 너클(2.75mm 구멍)에 직접 셀프탭.
  * 패널쪽 너클(P) – 팬쪽 너클(F) – 패널쪽 너클(P) 순서. 나사를 조이면 P 두 개가 F를 양쪽에서 눌러 **마찰로 각도 유지**.
  * 나사가 패널쪽 부품에만 물려 있어서 팬을 돌려도 나사가 같이 돌지 않음 → 풀림 없음.
* 팬 고정도 **M3×40** — 팬 두께 25 + 뒤 플랜지 4 + 앞 플랜지/보스 11 = 정확히 40mm. 나사 끝이 보스 끝과 일치.
* 힌지 축 위치: 패널 앞면에서 **6.5mm**, 패널 끝에서 2mm 바깥. 팬 옆면은 축에서 10mm.
* 컨트롤 블록: 스케치처럼 **팬 바로 아래, 힌지 쪽**에 슬리브로 일체화. 노브 면이 앞(팬 정면과 같은 방향), USB-C/4pin 면이 뒤.
  * 앞뒤 모두 큰 창, 블록은 바깥쪽 열린 끝으로 밀어 넣고 끝단 걸림턱(0.6mm)으로 고정.
* 케이블: 블록 뒤 창 → 브래킷의 클립(슬리브 옆) → 브래킷 클립(가운데) → **두 힌지 사이 32mm 빈 공간**으로 축을 넘어감 → 패널쪽 클립 → 패널로.
  * 축 근처로 넘기면 팬을 돌려도 케이블 길이 변화가 거의 없다.
* 패널 고정은 v1에서 검증한 **훅 + 잠금 키** 재사용(철물 불필요). 훅 2개를 가장자리 열의 80mm 떨어진 슬롯 2개에 건다.

### 출력 방향 / 시행착오
1. 팬 브래킷을 뒷면을 베드에 놓고 출력하면 **앞 플랜지가 14mm 허공 캔틸레버** → 실패.
   * 해결: **세워서 출력**(슬리브 바닥이 베드). 웹·플랜지·힌지 너클이 전부 수직 벽이 되고 너클 구멍도 수직.
   * 앞쪽 나사 보스와 케이블 클립 아래에 45° 거셋을 넣어 서포트 없이 출력.
2. 세워서 출력하면 **팬쪽 너클(F) 아랫면 2곳**은 마찰면이라 깎을 수 없어서 오버행으로 남음 → 여기만 서포트 사용.
3. F 너클을 뒤판까지 보강하는 웹이 처음엔 **패널 모서리를 파고듦**(간섭 58mm³) → 45° 평면으로 잘라 패널 모서리를 피하면서 그 면 자체가 출력 가능한 경사가 되도록 함.
4. 블록 걸림턱이 블록 끝과 겹침 → 슬리브를 2.5mm 늘려서 블록과 턱 사이 0.4mm 여유 확보.
5. 회전 범위 확인: **0°(패널과 같은 평면) ~ 97°(패널 앞으로 직각 이상)** 간섭 없음. 0°에서 패널에 닿아 자연스러운 스토퍼가 됨.

## 조립
1. **패널 리프**의 훅 2개를 패널 가장자리 열의 슬롯 2개(80mm 간격)에 꽂고, 아래로 약 7mm 밀어 건다 → **잠금 키**를 위쪽 홈에 꽂는다.
2. 컨트롤 블록을 **노브가 앞(브래킷 앞 플랜지 방향), USB-C가 뒤**로 오게 슬리브 열린 끝으로 밀어 넣는다.
3. 팬을 브래킷 C채널에 끼우고, **M3×40 2개**를 뒤쪽에서 팬 모서리 구멍을 통해 앞 보스에 조인다.
4. 팬쪽 너클을 패널쪽 너클 사이에 맞추고 **M3×40 2개**를 위·아래 바깥쪽에서 꽂아 조인다. 원하는 뻑뻑함이 될 때까지 조임.
5. 케이블: USB-C → 뒤 창 → 브래킷 클립 2개 → 두 힌지 사이로 축을 넘어 → 패널 리프 클립. 4pin은 뒤 창에서 팬 커넥터로.

## 파라메트릭 수정
`asset/skadis_fan_mount/skadis_fan_mount.py` 상단 값을 바꾸고 실행하면 STL 재생성.
```bash
pip install manifold3d numpy          # render_preview.py 는 matplotlib, scipy 추가
python3 skadis_fan_mount.py           # STL 생성
python3 render_preview.py 45          # 미리보기 PNG (힌지 각도)
```
| 파라미터 | 기본값 | 용도 |
| :--- | :---: | :--- |
| `EDGE_TO_COL` | 20 | **패널 끝 ~ 가장 가까운 슬롯 열 중심 거리** (실측 필요) |
| `HOOK_SLOT_Y` | (-40, 40) | 훅을 걸 슬롯 위치(팬 중심 기준) |
| `KN_GAP` | 0.25 | 힌지가 너무 뻑뻑/헐거우면 조정 |
| `M3_TAP` | 2.75 | 나사가 안 들어가면 2.9, 헛돌면 2.6 |
| `MOD_CLR` | 0.4 | 블록이 빡빡하면 +0.2 |
| `CABLE_D` | 5.0 | 클립에 들어갈 케이블 굵기 |
