# 스카디스 120mm 팬 마운트 제작
> 책상 아래 스카디스 패널 끝에 120mm PWM 팬을 달아 PC 주변에 바람을 보내기 위한 거치대.
> 팬 각도를 자유롭게 바꿀 수 있어야 하고, USB-C 팬 컨트롤러 모듈도 같은 패널에 붙이고 싶다.

## 사용 하드웨어
| 종류 | 명칭 |
| :---: | :--- |
| 3d 프린터 | Bambulab A1 |
| 필라멘트 | PETG 권장 (PLA도 가능) |
| 팬 | 120mm 4pin PWM 팬 (ARCTIC, 두께 25mm) |
| 컨트롤러 | USB-C 입력 / 4pin 출력 팬 속도조절 모듈 (44.90 × 21.92 × 17.40mm) |
| 공구 | 디지털 버니어 캘리퍼스 |
| 체결 | M5×25 볼트 2개 + M5 너트 2개 (고프로 썸스크류 호환), 팬 나사 2개 |

### 브레인스토밍(메모장)
* 스카디스 규격: 슬롯 5 × 15mm, 같은 열 슬롯 간격 40mm(지그재그로 20mm 오프셋), 판 두께 5mm.
* 패널이 수직이 아닐 수도 있다(사진상 거의 눕혀져 있음) → 중력만으로 걸리는 훅은 빠질 수 있다.
  * **아이디어**: 훅을 걸고 아래로 내리면 슬롯 위쪽에 약 8mm 빈 공간이 남는다. 여기에 **잠금 키**를 꽂으면 어느 방향으로 달아도 안 빠진다.
* 각도 조절 방식
  * 볼조인트: 예쁘지만 출력 공차에 민감하고 팬 무게에 처질 수 있음
  * 로제트(톱니) 힌지: 각도가 단계로 끊김
  * **고프로식 3발/2발 힌지 + M5 볼트**: 마찰로 무단 고정, 공차 여유 큼, 고프로 액세서리와 호환 → 채택
* 힌지 하나는 1축 회전뿐 → **암 양 끝의 힌지 축을 90° 비틀어서** 2축(틸트 + 스윙) 조절.
* 팬 고정: 팬 한쪽 모서리의 나사구멍 2개(간격 105mm)만 사용하는 바 형태 → 바람길을 거의 안 막음. 팬 옆면을 감싸는 립을 넣어 위치 고정 + 강성 확보.
* 컨트롤러 모듈: 노브/USB-C/4pin 케이블 위치를 정확히 모르니 **윗면은 완전 개방, 사방에 창**을 내고 양 끝 립으로 스냅 고정.

### 출력 방향 고민 (가장 시행착오가 많았던 부분)
1. 처음엔 베이스를 옆으로 눕혀 출력하려 했는데, 힌지 축이 수직이 되면서 **위쪽 발(프롱)이 3.3mm 틈 위로 통째로 오버행** → 실패 예상.
   * 해결: 베이스 힌지 축을 슬롯 방향(Z)으로 돌려서, 옆으로 눕혀도 프롱이 세워진 판이 되게 함.
2. 훅(페그)이 판 가운데 있으면 옆으로 눕혔을 때 **허공에 뜬 8mm 캔틸레버** → 출력 불가.
   * 해결: 판 가장자리를 훅과 같은 면에 맞춤(훅이 베드에 바로 닿음). 힌지는 슬롯에서 8.8mm 옆으로 오프셋.
3. 암은 양 끝 힌지가 90° 꼬여 있어서 어떻게 눕혀도 한쪽 프롱은 수평 오버행이 생김.
   * 해결: **암을 길이 방향으로 45° 굴려서 출력** → 양 끝 프롱 모두 45° 경사(서포트 불필요). 바닥에 용골(keel)을 달아 접지면 확보.
4. 모듈 홀더의 위쪽 코너 기둥이 허공에 뜸.
   * 해결: 양 끝 벽을 '창틀' 형태로 바꿔서 창 위쪽이 14mm 브릿지가 되도록 함. 립도 창틀 상단 가로대에 달아 스냅 고정력 증가.
5. 힌지 웹을 베드까지 끌어내리니 암이 한쪽으로 30°밖에 안 돌아감 → 암 프롱 길이를 늘려 **힌지1 ±95°, 힌지2 -100°~+105°** 확보 (간섭 체크로 검증).

## 조립
1. **베이스** 훅 2개를 같은 열의 슬롯 2개(40mm 간격)에 꽂고 → 훅 방향으로 약 7mm 밀어 건다.
2. 판 위쪽의 홈으로 **잠금 키**를 끝까지 꽂는다 (훅이 다시 올라오지 못하게 막음). 빼려면 키 손잡이를 잡아당기면 됨.
3. **팬 브래킷**을 팬 한쪽 모서리 구멍 2개에 팬 나사로 고정 (립이 팬 옆면에 닿도록).
4. 베이스(3발) ← 암(2발) → 팬 브래킷(3발)을 **M5×25 볼트 + 너트**로 연결. 너트는 육각 홈에 끼우고 볼트를 조여 원하는 각도에서 고정.
5. **모듈 홀더**를 원하는 위치에 같은 방식(훅 + 잠금 키)으로 걸고, 모듈을 위에서 눌러 끼운다(양 끝 립 스냅).

## 파라메트릭 수정
`asset/skadis_fan_mount/skadis_fan_mount.py` 상단 파라미터만 바꾸고 다시 실행하면 STL이 재생성됨.
```bash
pip install manifold3d numpy          # (render_preview.py 는 matplotlib, scipy 추가)
python3 skadis_fan_mount.py           # STL 생성
python3 render_preview.py 30 -60      # 미리보기 PNG (힌지1 각도, 힌지2 각도)
```
| 파라미터 | 기본값 | 용도 |
| :--- | :---: | :--- |
| `PEG_W` / `PEG_H` | 4.4 / 7.0 | 훅이 빡빡하거나 헐거우면 조정 |
| `PRONG_GAP` | 3.3 | 힌지가 안 들어가면 +0.1~0.2 |
| `BOLT_D`, `NUT_AF` | 5.3 / 8.3 | M5 기준. M4 쓰려면 4.3 / 7.3 |
| `MOD_CLR` | 0.4 | 모듈이 빡빡하면 +0.2 |
| 암 길이 | 50, 80 | `build()`의 `for L in (50, 80)` 수정 |
