# 가속도 트래커 케이스 제작
> 가속도 트래커 모듈을 보호하고 착용할 수 있도록 케이스 및 스트랩 결합용 플레이트 제작

## 사용 하드웨어
| 종류 | 명칭 |
| :---: | :--- |
| 3d 프린터 | Bambulab A1 |
| 필라멘트 | Esun PLA trans |
| 공구 | - |

## 사용 소프트웨어
| 종류 | 명칭 |
| :---: | :--- |
| 슬라이서 | Bambu Studio |
| 모델링 툴 | Autodesk Fusion |


### 브레인스토밍(메모장)
* 트래커 모듈을 안전하게 보호하면서 내부 LED 상태 표시등이 투과되어 보일 수 있는 구조여야 한다.
* 벨크로 스트랩을 연결하여 몸이나 착용 부위에 고정할 수 있는 슬롯 구조의 백플레이트가 필요하다.
* 상부 및 하부 케이스는 내부 기둥(Boss) 체결 구조를 활용해 결합 시 유격 없이 고정되도록 한다.
* 반투명 필라멘트를 사용하면 별도의 타공 없이도 내부 LED 동작 상태를 직관적으로 확인할 수 있다.

## 과정
1. 가속도 트래커 및 부품 치수를 측정 후 Autodesk Fusion에서 모델링 스케치한다
![가속도 트래커 스케치](/asset/trackerCase_sketch.png )
2. 모델링 완료 후 STL 익스포트 -> 슬라이서에 임포트 후 출력
3. 출력 후 스트랩 결합 및 트래커 모듈 장착 후 동작 확인
![가속도 트래커 실물](/asset/trackerCase.png )
