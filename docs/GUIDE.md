# 3D Printer Documentation 작성 가이드라인
3D프린터 관련 기록을 작성하는 형식을 대략적으로 정의하는 문서입니다.

### 파일명 작성 표준
* **형식:** `YYYY-MM-DD-주제 요약.md` (영문 소문자 및 하이픈`-` 사용 권장)
* **예시:** 
  * `2026-08-19-esun-pla-retraction-tuning.md`
  * `2026-08-20-belt-tension-adjustment.md`

### 파일 내용 작성 표준
| 구분 | 형식 |
| :---: | :--- |
| **Trouble Shooting** | 현상 - 원인 분석 - 조치 - 결과 |

### 파일별 추가 작성 요령
* [**Troubleshooting Logs**]
    * 문제가 해결되는 시점까지 하나의 파일에서 작성.
