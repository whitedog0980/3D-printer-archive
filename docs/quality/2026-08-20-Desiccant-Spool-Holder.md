# [품질] 내습 스풀 홀더
* **작성일지 :** 2026-08-20


## 목적
> [밤부랩 AMS시스템](https://wiki.bambulab.com/ko/filament-acc/filament/tpu-85a-90a-printing-guide-for-a-series)은 TPU 필라멘트를 지원하지 않는다 또한 TPU소재는 습도에 취약하므로, 내습 스풀 홀더를 제작한다.
* **참조자료 :** [프로젝트 링크](https://makerworld.com/en/models/1233835-retracting-spool-holder#profileId-1274991)

## 제작 환경 및 조건
| 항목 | 내용 |
| :--- | :--- |
| **프린터 모델** | Bambu Lab A1 |
| **사용 필라멘트** | Esun Pla basic, Esun Tpu |
| **환경** | 베란다-습도:70%, 기온 25~30 |
| **초기 내부 습도** | 45% |
| **목표 내부 습도** | 20% |
| **특이사항** | ams 내습 인클로저 사용-내부 습도:45% |

## 제작 과정
* 기대 자원 소모 : 필라멘트 약 850g, 21시간
* 트러블 발생 : [**오버행 붕괴**](./docs/troubleshooting/)
